## Writing Rules

- Record only durable facts that remain useful across sessions.
- Put transient progress in `history_log.md`.

## Knowledge Entries

### Task History Session Metadata

When a task history log appends a later session, the `METADATA:SESSION` header
should advance to the latest session number so machine-readable task state does
not lag behind the human-readable log.
